# 参数说明

`start-llama.sh` 里每个参数为什么这么设。只在一台机器上测过（见 README「实测环境」），换了显卡、内存或 llama.cpp 版本，数字会变。

## 放显卡还是放内存

| 参数 | 作用 | 为什么 |
|---|---|---|
| `--fit on` | 按显存自动分配：放不下的部分挪到内存 | 这一版默认就是 `on`，写出来是为了看得清楚。不用手算 `--n-cpu-moe`。用 llama.cpp 自带的 `llama-fit-params` 看过分配结果：上下文 32k 时，第 20–40 层的专家权重（外加第 19 层的 down）放内存，其余全在显卡上 |
| `--device CUDA0` | 只用这一块显卡 | 明确指定独显；多显卡的机器按自己的改 |
| `-c 32768` | 上下文 32k | 给 Agent 用，16k 不够：工具说明 + 几轮工具结果很快就满，反复压缩会拖慢很多（见 README「实测」） |
| `-ctk q8_0 -ctv q8_0` | KV 缓存用 8 位 | 省显存，好让更多层留在显卡上 |
| `-np 1` | 只开一个槽位 | 一个人用；多开几个槽位，KV 缓存也要多占几份 |
| `--load-mode none` | 不用内存映射加载模型 | **这是 32 GB 机器上最关键的一个参数**，见下面 |

### 为什么要 `--load-mode none`

默认（`auto`）会把模型文件映射进内存。实测：

| 加载方式 | 进程常驻内存 | 显存 | 测试期间系统剩余内存最低 | 生成速度 |
|---|---|---|---|---|
| 默认（映射） | 最多 1.6 GB，但整个模型文件（16.5 GB）的页面都挂在进程上 | 9.8 GB | **0.34 GB** | 约 51 token/秒 |
| `--load-mode none` | 最多 10.3 GB（放内存的专家 + 缓存） | 9.9 GB | 5.1 GB | 约 62 token/秒 |

映射时，放到显卡上的那部分权重在文件缓存里也留着一份，32 GB 内存差点被吃光。llama.cpp 自己也会提示「专家放 CPU 时，用映射会更慢」。不映射之后，只有放内存的那部分专家常驻，速度也更快。

### 看占多少内存，别看「私有字节」

在 Windows 上，刚加载完、还没收到请求时，llama-server 的「私有字节 / 提交大小」就有约 11 GB，其中约 9.5 GB 是 152 块 64 MB 的分配，大小和显存用量几乎一样，看起来是显卡驱动给显存记的账（只算提交量，没占内存条）。要看真实占用，看性能计数器 `\Process(llama-server)\Working Set - Private`，再加上显存。

## 采样（防复读）

| 参数 | 值 |
|---|---|
| `--temp` | 0.7 |
| `--top-p` | 0.8 |
| `--top-k` | 20 |
| `--min-p` | 0 |
| `--dry-multiplier` | 0.8 |

前四个是 Qwen3 系列非思考模式的官方推荐值。原先用 llama.cpp 的默认值（温度 0.8、top-k 40、top-p 0.95、不防复读）时，Agent 在填工具参数时两次陷进复读：一个短名字被写成同一串字反复重复，一直写到 4096 的输出上限。换成上面这组 + DRY 之后没再出现过。

DRY 只惩罚重复出现的一整段；换行、冒号、引号、星号是断点、不罚，所以 JSON 里反复出现的引号不受影响。

很多 Agent 客户端不传采样参数，这时就用这里的服务端默认值，所以写在启动脚本里。

## 关掉思考

`--jinja --reasoning-format deepseek --chat-template-kwargs '{"enable_thinking":false}'`

- `--jinja`：按模型自带的模板生成工具调用，Agent 要用
- 关思考：在服务端关，客户端不用管。之前在同一台机器上跑稠密的 27B 模型时，开着思考常常一轮答不完；换成这个 MoE 模型后一直关着用，没再试过开
- 这一版的 llama.cpp 已经有新写法 `--reasoning off`，`--chat-template-kwargs` 的写法标成了过时，但现在还能用。脚本里用的是实测过的旧写法

## 安全

llama-server 的默认设置是给本机试玩用的：不要密钥、跨域允许任何来源（`--cors-origins` 默认 `*`）、`/slots` 能看到正在处理的对话。意思是你浏览器里开着的任何网页都能在后台调你的模型、读你的对话。所以：

| 参数 | 作用 |
|---|---|
| `--host 127.0.0.1` | 只听本机，局域网连不进来 |
| `--api-key-file` | 要密钥；密钥放在文件里，不写进命令行（命令行别的进程看得到） |
| `--cors-origins localhost` | 跨域只认本机来源 |
| `--no-slots` | 关掉 `/slots` |

## 别名

`--alias qwen3.6-35b-a3b`：接口里的模型名。客户端（Agent）配置里的模型 id 要和它一样。
